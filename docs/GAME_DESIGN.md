# 3D quality-engineer-day — 設計規格

獨立專案，不修改 2D 原版。顯示名稱《品保工程師的一天 3D》，虛構場景「第零製造所」。所有組織、人物、品牌、批次與情節均為虛構；NPC 使用職稱，無可識別資訊。參考作品只作為斜俯視、方塊角色與走動互動的風格參考，資產、文案與程式為本專案自行建立。

## 3D 與操作

Three.js、正交斜俯視鏡頭、方塊人物與低多邊形設備。場景包含進料、供應商、CNC/CMM、焊接、研發、液冷測試、出貨、辦公區、午餐區與門禁。WASD/方向鍵移動；滑鼠點地板尋路；E 或互動按鈕與附近站點對話；任務面板「帶我去」尋路到互動位置。手機方向控制與互動按鈕。設備與牆體有碰撞，避免穿模。換裝閘門和管制區牆體是功能性設計，不是裝飾。

## 液冷管制區

西側閘門是唯一入口，未換無塵服不能通行。閘門互動可刷卡、更換無塵服並開門；人物衣服、頭罩與口罩改變，識別證/職能保留。進入測試站後可能發現序號清單在桌上、排程取消後恢復或客戶照片改批次。必須親自取得資料、回閘門再次換裝再進站。離開管制區自動換回工作服，換裝次數/時間/壓力記入本輪。重複換裝動畫很短且可減少動態。

## 多主線

新局從三條主線抽一條，優先抽收藏中尚未走完的主線，存檔固定路線不因重新整理變動。

1. **消失的序號**：箱號混批 → 外包紀錄 → CNC 量測 → 換裝進液冷站 → 清單在辦公桌 → 重新進站 → EC 履歷 → CQE 支援 → 出貨 → 午餐/交接 → 下班。
2. **今天一定要出貨**：包材與機櫃缺件 → 來料 → 焊接交班 → RD 特採 → 進液冷站 → 排程取消 → 回研發確認恢復 → 重新進站 → 大品牌客訴插單 → 出貨 → 午餐/交接 → 下班。
3. **客戶說漏了**：舊客訴 → 出貨批號 → 外包追查 → CNC 量測 → 進液冷站 → 客戶改照片/批次 → 回客訴窗口 → 重新進站 → RD 界定變更 → 午餐/交接 → 下班。

每條主線有自己的任務鏈、文本、處置與條件；不是僅更換開場標題。完成主線後可直接下班，也可接電話進入家中場景，追加三個夜間任務。主線都可觸及 IQC/SQE/PQE/IPQC/FQC/CQE/OQC 中多種代班，並以指定事件累積熟練度；兩次取得本輪永久資格。

## 第四條隱藏主線

**保固過了，服務沒有下班**。當主線 CQE 事件揭露已過保、沒有近期新訂單、重複支援紀錄，玩家使用 CQE 選「查閱歷次承諾與服務範圍」觸發。這條線不參與開局抽選；當日原主線被暫停並保留待交接事項，統計、支線、插單不清零。

隱藏任務：歷史承諾 → 業務/核准窗口 → 液冷換裝 → 換好才知道客戶沒給序號 → 出站追資料 → 再換裝確認證據 → 研發界定服務 → CQE 回覆 → 交接原案與離場。可選免費無限承接、直接拒絕或把異常調查與服務範圍分開，建立付費/例外核准、責任窗口、結束條件。過保不代表產品沒有異常。

四結局：品牌很滿意，你很不見／回覆已寄出，業務正在打電話／服務可以延續，範圍必須確認／隱藏「未來訂單，請提供單號」。成功條件需要歷史證據、明確範圍與原案交接，不單看數值。

## 支線與插單

三條可獨立探索的支線，每條三階段：供應商 CAR 閉環（供應商→CMM→出貨）、批次追溯（進料→液冷站→研發）、便當保衛戰（午餐→客訴→門禁）。每階段有結果與獎勵，已完成階段不能重複刷分。任務列表可以導航支線，主線進度不因此跳過。

六件隨機插單，每輪抽兩件不重複，在主線第 3、6 個節點插入，處置完才回原案：CMM 校驗、來料照片、巡檢複製、受潮包材、特採期限、外包異常。插單是待處理任務，有實際站點與代班，而非只在訊息中出現。

## 指標與保存

品質70、壓力24、信用50起始；範圍0–100。停線與加班分鐘累積；換裝次數與花費時間獨立呈現。事件時間由工作日節點排定，移動本身不處罰，換裝與事件會改變指標。預覽包含職能加成與上限。不存在真實測試規格或實際放行指引。

使用獨立 localStorage 命名空間；保存路線、角色位置、衣服/閘門、進度、隨機插單、支線、結果頁與收藏。新局保留已完成路線與結局；兩個專案存檔互不影響。結局可匯出交接文字。

## 完成範圍與擴充

本版必須實際實作可走動碰撞場景、換裝閘門、三主線隨機分配、CQE 隱藏接管、三支線、兩次隨機插單、夜間家中場景、結局收藏與存檔。後續可擴充實際圖面對照小遊戲、多樓層、多日章節、NPC 排程、聲音與虛構模型資產。本版沒有連線多人、伺服器或真實公司資料。
