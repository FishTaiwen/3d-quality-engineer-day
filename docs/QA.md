# 3D MVP 驗證紀錄

日期：2026-10-07。Node.js 純規則測試，以及本機靜態伺服器上的 Codex 內建瀏覽器實際操作。

## 已驗證

- 三條普通主線從種子抽取；已完成路線會避開，直至三條都完成。相同種子重現同一主線與兩個不重複插單。
- 5,000 個完整模擬工作日，以及明確的結局路徑測試：13 結局可達成、三條普通主線都有好/疲累/風險結局、隱藏線四結局。
- CQE requiredRole 條件；切換為其他職能不能觸發接管。接管保存原案、原時間、支線與累積數值；原案證據不能冒充大品牌案件的新調查證據。
- 三支線各三階段的結果快照、完成獎勵、防止重複刷分，以及完成後回到原主線。
- 每個工廠站點均可尋路抵達。鎖門時，從門外到液冷站的 BFS 找不到路；開門後可達。家中出生位置與筆電可達性均有碰撞回歸測試。
- 實際瀏覽器走過進料、供應商、CMM、出貨插單等站點；設備碰撞與「帶我去」沿地板尋路。
- 實際完成「換無塵服→進測試站→清單沒帶→出站換回工作服→回桌取清單→再次換裝→重新確認」；沒有穿牆或卡在閘門。
- 實際觸發並完整完成第四條隱藏主線；原案待交接顯示、四次換裝成本、大品牌新證據、原案交接與「未來訂單，請提供單號」結局均確認。
- 實際完成另一輪序號普通主線、整條追溯支線、兩個插單、日班離場電話、家中三個夜間事件與結局；加班分鐘累積正確。
- 工廠/隱藏線與家中階段重新整理接續，位置、服裝、待處置事件與收藏保留。
- 390×844 手機尺寸：頁面不超出視窗寬度、角色避開任務面板、方向按鈕、觸控互動、手機說明與 Esc 關閉。已保存手機畫面。
- 報告預覽有完整主線、原案、指標、職能與交接文字，以及標準 Blob 下載連結。
- 以上兩輪遊玩未出現 JavaScript error / warning。Three.js、素材與字型均不需外部 CDN；場景由程式產生。
- 2D 原版與其存檔命名空間保持分離；新專案部署不必覆蓋原版。

## 限制與後續驗證

- 普通序號線與隱藏線已完整實際走通；出貨線手機首事件已操作，出貨線/客訴線全流程另外由規則測試驗證，尚未各自完整人工走一次。
- 手機是視窗模擬，尚未在實體 Android/iOS、Firefox/Safari 或低階 GPU 逐一測試。需要 WebGL 2；無 WebGL 2 時會顯示啟動失敗說明。
- 已備妥 GitHub Pages 靜態結構與相對路徑，尚未為使用者建立儲存庫或公開部署。
- 下載連結與文字預覽已確認；內建瀏覽器不提供可靠的落地檔案路徑，因此尚未驗證外部瀏覽器實際下載檔案。
- 規則為敘事模型。事件時鐘、更衣、停線與加班是獨立計數；移動不消耗工時。沒有真實品質判定標準。
- NPC 為靜態站點角色，有玩家步行動畫、換裝與光影；未做 NPC 自主排程、多人連線、跨日職涯或音效。
- 自動存檔限同來源/瀏覽器，最多保存近期120筆交接，永久職能限本輪，跨新局保留結局與已完成普通主線。
